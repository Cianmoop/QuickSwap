# QuickSwap

开源、免费的跨平台工具：在局域网内直接批量传输照片与视频，不经过云端，保留原始画质，支持增量跳过已存在文件。

## 功能

- 批量选择相册中的照片与视频
- 发送端启动临时 HTTP 服务，接收端通过二维码或 IP 连接
- 流式传输，避免一次性加载大文件到内存
- 按「文件名 + 大小」指纹做增量比对，跳过本地已有项
- 传输时保持屏幕常亮（`wakelock_plus`）

## 环境要求

- Flutter 3.x
- Android 6.0+（当前主要面向 Android 真机调试）
- iOS 12+（已配置权限说明，需进一步真机验证）

## 快速开始

```bash
cd quick_swap
flutter pub get
flutter run
```

两台手机连接**同一 Wi‑Fi**，或由**发送端开启热点**、接收端连上后再传输。

### 使用流程

1. **发送端**：主页 →「发送」→ 勾选媒体 →「开始传输」→ 展示二维码与地址  
2. **接收端**：主页 →「接收」→ 扫码或输入地址 → 连接 → 确认列表 →「开始下载」

## 打包

```bash
flutter build apk --release
```

输出：`build/app/outputs/flutter-apk/app-release.apk`

## 常见问题

| 问题 | 建议 |
|------|------|
| 连接失败 | 确认同一局域网；关闭 VPN；尝试热点模式 |
| 相册为空 | 授予照片/视频读取权限 |
| 传输中断 | 保持发送端页面在前台；重新连接后可增量跳过已下载项 |
